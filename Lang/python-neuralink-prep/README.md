# Python Refresh For Robotics SWE Interviews

This curriculum is a beginner-to-advanced Python refresh for robotics software interviews. For a robotics SWE role, Python is usually not the lowest-level robot control language, but it is extremely useful for tooling, simulation, data analysis, testing, automation, perception experiments, and debugging workflows.

The necessary number of files is 14:

- `README.md`: overview and how to use the curriculum.
- `00-roadmap.md`: schedule, expectations, and final project.

## How To Study

For each lesson:

1. Read the explanation.
2. Type the examples manually.
3. Complete the exercises without copying full solutions.
4. Run your code with clear test cases.
5. Write down mistakes and the rule you learned.

Python can make simple things easy, but interview-quality Python still requires rigor: clear data models, explicit errors, good tests, predictable performance, and readable code.

## Expected Outcome

By the end, you should be able to:

- write clean Python scripts and modules;
- use core data structures fluently;
- test and debug Python programs;
- use type hints to communicate design;
- build small command-line tools;
- process robot logs or sensor data;
- reason about performance limits;
- explain concurrency tradeoffs;
- design safety-aware robotics tooling.
